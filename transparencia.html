TRANSPARENCIA

Cómo funciona Gibraltar Watch

La automatización solo es útil si el lector puede saber qué se ha medido, qué se ha inferido, cuándo se consultó y qué puede estar desactualizado.

PRINCIPIOS

Reglas que no se negocian

1 · Hechos

Los datos y afirmaciones verificables se atribuyen a su fuente. Cuando una fuente es antigua o no responde, se muestra la frescura en lugar de ocultarla.

2 · Interpretación

Los indicadores editoriales sintetizan señales, pero no se presentan como comunicados oficiales ni sustituyen avisos de navegación, seguridad o protección civil.

3 · Escenarios

Las hipótesis se etiquetan como escenarios. Una tensión política, un titular o un sismo no prueban por sí solos una interrupción del Estrecho.

4 · Automatización e IA

El Diario puede apoyarse en un modelo de lenguaje cuando está disponible y dispone de reglas de seguridad editorial. Si no está disponible, existe una generación determinista. El motor utilizado se publica en cada edición o metadato asociado.

5 · Frescura

Cada capa tiene umbrales de frescura distintos. El sistema reduce la confianza cuando las fuentes críticas envejecen o faltan archivos.

6 · Anomalías

Las desviaciones se calculan contra el histórico propio y solo sirven como señal de revisión. En sismicidad no se interpretan como predicción de terremotos.

SALUD DEL SISTEMA

Qué está fresco y qué no

Este diagnóstico se genera en el mismo ciclo de actualización y forma parte de la información pública del observatorio.

PUBLICACIÓN SEGURA

Fallará antes de publicar algo roto

Validación previa al commit

La nueva cadena verifica JSON, páginas críticas, sitemap, RSS, enlaces internos básicos y la configuración sensible del workflow antes de hacer push.

Recuperación

La web se construye en el checkout de GitHub Actions y solo se confirma si supera las pruebas. El historial de Git conserva cada versión publicada, permitiendo revertir a un commit anterior sin acumular copias ZIP dentro del repositorio.

COMERCIAL

Publicidad separada de los indicadores

Los espacios publicitarios y patrocinios deben estar identificados y no pueden modificar estados, confianza, fuentes, cronología, anomalías ni conclusiones editoriales. Las alertas por correo permanecen en modo de solicitud manual hasta que se conecte un proveedor con consentimiento y baja gestionables.
